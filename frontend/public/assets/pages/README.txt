# UabIndia Page-Wise Asset Structure Guide
# Location: frontend/public/assets/pages/

Agar aapko kisi bhi page (Home, About, Contact, Pricing, Helpdesk) me image add karni ho,
toh us page ke respective folder me image file save karein:

1. HOME PAGE (/):
   Folder: frontend/public/assets/pages/home/
   Example File: banner.png ya feature.jpg
   Usage URL in code/admin: /assets/pages/home/banner.png

2. ABOUT PAGE (/about):
   Folder: frontend/public/assets/pages/about/
   Example File: company-story.png ya team.jpg
   Usage URL in code/admin: /assets/pages/about/company-story.png

3. CONTACT US PAGE (/contact):
   Folder: frontend/public/assets/pages/contact/
   Example File: support-team.png ya office.jpg
   Usage URL in code/admin: /assets/pages/contact/support-team.png

4. PRICING PAGE (/pricing):
   Folder: frontend/public/assets/pages/pricing/
   Example File: enterprise-plan.png
   Usage URL in code/admin: /assets/pages/pricing/enterprise-plan.png

5. HELP & SUPPORT PAGE (/help-support):
   Folder: frontend/public/assets/pages/help-support/
   Example File: knowledgebase-banner.png
   Usage URL in code/admin: /assets/pages/help-support/knowledgebase-banner.png

NOTE:
Next.js me `public/` directory ke andar jo bhi files ya folders hote hain,
wo directly web browser me `/assets/...` bankar accessible hote hain.
